Locky 1.3.3 · PhoneStart Activity preview

- 시작화면 체크 메모를 13px 글자와 일정한 간격으로 정리하고 구분선을 제거했습니다. 삭제 버튼은 편집할 때만 표시하며, 하단 스크롤 끝까지 항목을 읽고 편집할 수 있습니다.
- 메모 위젯을 120dp 최소 너비와 Android 12+ 가로 2칸 기본 크기로 조정했습니다. 작은 크기는 제목·확대 버튼, 넓은 크기는 메모 전환 버튼을 함께 표시합니다.
- 위젯 체크박스를 일관된 그래픽으로 바꾸고 직접 완료·해제를 지원합니다. 체크 변경은 최신 항목을 검증해 반영하며, 편집 중인 메모와 다른 위젯의 변경을 보존합니다.

기존 설치 위에 Locky.apk를 설치할 수 있으며 기존 서명과 사용자 데이터를 유지합니다.
삼성 One UI의 실제 2칸 배치와 홈 화면 터치·크기 조절은 실기기 확인이 필요합니다.
