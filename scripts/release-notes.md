Locky 1.2.2

기존 설치와 같은 앱 ID(com.locky.app)와 서명을 유지합니다.

- 사전 전용 두 번째 WebView와 시작화면 초안 복사·복원을 제거했습니다. 창 계층에 필요한 최소 Activity에서 기존 WebView 자체를 재사용하고, 창을 옮길 때만 메모리에 유지한 직전 화면으로 빈 프레임을 막습니다. 다음사전의 PROCESS_TEXT·작은 검색 전용 task 플래그는 유지합니다.
- 사전 선택은 기존 화면의 선택창에서 처리합니다. 선택 후 명시적으로 검색을 실행하므로 선택창 실행만으로 성공 처리하지 않습니다. 실제 Android 사전 실행 호출이 성공한 뒤 입력창과 검색어 초안을 비우고 실패·취소 시 유지합니다.
- 휴대폰 시작화면의 '그냥 끄기'는 홈 이동과 선제적인 화면 제거 없이 잠금을 요청합니다. 화면 꺼짐 이벤트에서 기록과 세션을 정리하며 중복 실행과 잠금 실패를 처리합니다. 관리 앱 취소는 기존 홈 복귀 동작을 유지합니다.
- 화면 꺼짐에서 한 번 준비하고 잠금 해제 신호를 한 경로로 모읍니다. 준비된 프레임은 단순 재노출 때 초기화하지 않으며 초기 로드·실제 detach·렌더러 종료와 느린 렌더링에 대한 기존 보호를 유지합니다.
- 시작화면 배치·메모 크기·여백·목적 선택 방식과 데이터 형식은 변경하지 않았습니다.

검증: 실제 app.js의 비동기 실행 응답·검색 성공/실패/재시도·반복 검색·최초 선택/취소·입력 중 새 단어·다른 초안과 목록 스크롤 보존을 표적 브라우저 검사했습니다. 릴리즈 작업은 사전 복귀·잠금/잠금 해제·렌더링·테마·타이머 관련 JVM 검사, lint와 서명·앱 ID 검사를 수행합니다.

실기기 확인 필요: 삼성의 실제 다음사전 알림/팝업 표시, 최초 창 이동과 복귀 시 깜빡임, 키보드·회전, 잠금/잠금 해제의 전환 감각과 장시간 화면 꺼짐 뒤 렌더링. 자동 검사는 이 사용감을 확인한 결과가 아닙니다.
