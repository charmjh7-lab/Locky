Locky 1.2.0

기존 앱에 덮어 설치하는 업데이트입니다. 패키지명, 설치 서명과 기존 메모·대화·목적·사용 기록을 유지합니다.

- 시작 화면: 상단 메모·ChatGPT·사전, 하단 목적 선택, 독립된 빨간 종료 버튼의 위계를 정리했습니다. 직접 실행 홈에서는 하단 탐색을 제공합니다.
- 앱 진입·연장·차단: 사용 시간과 목적, 처음 정한 목적과 추가 시간, 실제 차단 이유와 다시 사용할 시각을 구분합니다.
- 설정은 기능별 구획과 행으로 묶고, 브리핑은 수치·기록 해석·상세 기록을 나눴습니다. 메모는 편집 내용, ChatGPT는 답변 본문과 입력을 중심으로 정리했습니다.
- 시스템 라이트·다크 테마를 WebView·Android 배경·시스템 바·타이머 상세창에 적용했습니다. 테마 변경은 기존 화면과 입력을 유지합니다.

검증: 실제 화면 코드를 사용한 브라우저 검증과 대표 화면 시각 검토, Android 표적 JVM 회귀 검사·lint·서명 검사를 수행합니다. 삼성 실기기 설치·최근 앱 복귀·잠금 해제·사전 팝업·실계정 ChatGPT 검증은 별도 확인 대상입니다.
