Locky 1.3.11 — ROKI 원본 질감 보존 및 Adaptive Icon 정상 구성

패키지 com.locky.app, versionCode 35. 기존 signing/personal.p12 인증서와 앱 데이터, 기능 코드를 유지합니다.

- 사용자가 제공한 원본 이미지에서 잘라낸 녹색 아이콘을 무손실 WebP 원천 자료로 저장했습니다. 이전 5.5KB 중간 손실 WebP는 폐기했습니다.
- 녹색 그라데이션과 입자감은 원본의 실제 녹색 픽셀을 이용해 복원하여 불투명한 배경 PNG로 만들었습니다. 녹색 외부를 투명하게 하지 않습니다.
- 연두색 문/원근면과 흰색 L의 원본 색·광택을 투명 전경 PNG로 분리했습니다. 원본 사진의 크림색 외부는 어떤 레이어에도 들어가지 않습니다.
- 전경은 108dp 레이어의 약 54% 크기로 중앙 배치하여 72dp 표시 영역 안에 여백을 확보했습니다. 녹색 배경은 적응형 아이콘 전체를 덮습니다.
- 기존 이미지 생성기를 APK 빌드에서 실행하지 않습니다. 확정된 무손실 PNG 두 장을 그대로 저장소와 APK에 포함합니다.
- Android 테마 아이콘의 단색 형태도 새 문과 L 위치에 맞게 조정했습니다.

원본 복원 및 PNG 자산 재생성은 scripts/generate_roki_launcher_layers.py를 별도로 실행할 때만 수행됩니다.
