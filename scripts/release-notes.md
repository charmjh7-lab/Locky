Locky 1.3.12 — 집중시간 예고·시작 알림 수정

패키지 com.locky.app, versionCode 36. 최신 build 144의 ROKI 아이콘과 기존 서명·데이터를 유지합니다.

- 화면이 꺼져 있으면 집중시간 예고 알림을 생략하고, 다시 화면을 켜도 지난 예고를 재전송하지 않습니다.
- 집중시간 시작 시 알림을 한 번만 전송하며 기존 예고 알림은 시작 알림 하나로 교체합니다.
- 예고·시작 알림에 새 고중요도 채널을 사용하여 사용 중 상단 배너를 받을 수 있게 합니다. 이미 설치된 일반 중요도 채널도 업그레이드로 전환됩니다.
- 절전으로 시작 알람이 늦어져도 해당 집중시간 안에서 한 번 전달하며, 앱을 중간에 처음 실행했다고 시작 알림을 새로 만들지 않습니다.

실제 삼성 기기의 팝업 표시는 사용자 알림 설정·방해금지 설정의 영향을 받습니다. 실기기 표시는 자동 테스트로 검증하지 않았습니다.
