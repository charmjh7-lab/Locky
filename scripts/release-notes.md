Locky — 사실 기반 브리핑과 시작화면 동작 개선

기존 패키지와 개인 서명을 유지하는 업데이트입니다. 기존 목적·메모·대화·사용 기록과 현재 DB 스키마를 유지합니다. 릴리스 제목의 버전은 생성된 APK의 versionName을 사용합니다.

- 집중시간 설정 변경·시간대 이력을 기록하고, 사용 구간을 집중시간·자유시간·이력 미확인으로 나눕니다. 업그레이드 이전 집중시간을 현재 설정으로 추정하지 않습니다.
- 오늘의 기록, 종료된 집중시간 결과, 완성된 날짜와 주간 기록을 구분합니다. 목적·취소·연장·앱 사용 흐름과 근거가 있는 주요 기록을 표시하며 AI 평가를 생성하지 않습니다.
- 집중시간 종료 알림과 다음 날 기본 오전 9시 일일 알림을 분리합니다. 새 높은 중요도 배너 채널과 정확한 날짜·구간 진입, 중복 발송 방지를 적용했습니다.
- 시작화면에서 보낸 ChatGPT 질문은 뒤로가기로 시작화면에 복귀합니다. 일반 목록에서 연 대화는 목록으로 돌아갑니다.
- 목적 버튼은 날짜와 범위별 순서를 사용합니다. 같은 날 순서를 유지하고 다음 진입부터 새 날짜 순서를 적용합니다.
- 원본 JSON v1의 events·usage 형식을 유지하고 집중시간·관측 근거를 별도 필드로 추가합니다.
