# Locky — 제품 및 설계 원칙

이 앱의 목적은 사용자를 강제로 통제하기보다 스마트폰 사용 목적을 의식적으로 선택하도록 돕는 것이다. 시작 화면의 도구와 목적 선택은 명확히 구분하고, 종료·취소 경로를 쉽게 찾을 수 있게 한다. 기능을 단순 나열하거나 빈 공간을 채우는 것만으로 UI 개선을 완료했다고 판단하지 않는다.

앱 사용시간은 실제 전경 이용에 맞추어 집계하고, 시스템·보조 앱 중복, 화면 꺼짐·알림창·최근 앱 등 전환 상태를 고려한다. 플랫폼이 확인하지 못한 이용·목적을 추정해서 기록하지 않는다. 사용시간 예산·집중/자유 시간·사용 목적·메모·대화·브리핑의 지속성과 사용자의 선택을 보존한다.

시작 화면에서 입력한 ChatGPT 질문은 해당 질문이 저장된 대화로 연결되어야 한다. Android task 복귀·폴더블 UI·키보드·권한·백그라운드 제한 및 설치 업데이트 흐름을 함께 고려한다. 접근성·사용정보 권한은 필요한 범위에서만 사용하고, 민감한 인증정보나 이용 기록을 불필요하게 외부 전송하지 않는다.

기준: `README.md`, 현재 사용시간/접근성 서비스/목적 선택/브리핑/ChatGPT 연동 구현 및 테스트. 제품 원칙은 실제 지원 기능에 대한 확인을 대체하지 않으며 고정 서명과 기존 사용자 데이터 호환성을 보존한다.


## 작업 범위와 기존 UI의 우선 보존

이 문서의 사용성 개선 기준은 사용자가 요청한 화면/기능 범위에서만 적용한다. 기존 앱의 배치·여백·시각적 위계·버튼·문구·동작을 더 좋겠다는 이유만으로 변경하지 않는다. AI가 발견한 범위 밖 개선 사항은 `CHANGE_SCOPE_POLICY.md`에 따라 미적용 제안으로만 보고한다. 사용자가 승인하지 않은 디자인을 코드·테스트·제품 문서를 함께 변경해 확정 요구사항으로 만드는 행위를 금지한다.
